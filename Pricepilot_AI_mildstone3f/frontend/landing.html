About Us

Built for Enterprise Pricing

PricePilot AI is an enterprise-grade dynamic pricing intelligence platform built as part of the AI & Data Science Capstone Project (Milestone 3). The system empowers businesses to make data-driven pricing decisions using state-of-the-art machine learning models.

The platform integrates a LightGBM regression model for price optimization (R² = 1.0000, RMSE = $0.45) and an XGBoost model for multi-horizon demand forecasting (R² = 0.9050, MAE = 5.07 units) — trained on 7,300 real transaction records across 5 product categories and 15 SKUs.

The backend is powered by FastAPI with SQLite/PostgreSQL database support, JWT & OAuth 2.0 authentication (Google, GitHub, Microsoft), and direct Groq LLaMA-3.3-70B integration for on-demand AI recommendations. The frontend delivers a fully interactive SPA with Chart.js visualizations and PDF/CSV/JSON export capabilities.
