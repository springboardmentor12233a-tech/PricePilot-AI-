# Feature Selection

## Target Variable

The target variable for the planned demand prediction model is:

- Demand

## Candidate Features

### Pricing Features
- Price
- Competitor Pricing
- Price Difference
- Discount

### Sales Features
- Units Sold
- Units Ordered

### Inventory Features
- Inventory Level

### Marketing Features
- Promotion

### Product Features
- Product ID
- Category

### Location Features
- Store ID
- Region

### External Factors
- Weather Condition
- Seasonality
- Epidemic

### Time Feature
- Date

## Feature Selection Approach

Features will be selected based on:

- EDA results
- Correlation analysis
- Business relevance
- Data availability
- Machine learning model performance

## Target

Demand will be used as the target variable for demand prediction.
